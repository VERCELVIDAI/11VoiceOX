FAQ
Does it need an account or API key?
No. 11VoiceOX.in runs entirely on your machine. Clone, dub, and dictate without signing in or talking to a cloud API.
Desktop vs Docker — which should I use?
Desktop is the full app with auto-updates. Docker is the headless web UI (port 3900) for servers, homelabs and GPU boxes. Both run the same engines.
How much hardware do I need?
About 8 GB RAM (16 GB+ recommended) and ~10 GB disk for models. GPU optional — 4 GB VRAM works with CPU offload; no GPU is fine, just slower.
Where are older versions?
Every release and asset lives on GitHub Releases. Docker has :latest for the newest build and :rocm for AMD.
What is Beta?
Betas are test builds of the next release, published on GitHub before it ships. They get new features first and may be unstable. Use stable for day-to-day work; switch channels in Settings → About.
