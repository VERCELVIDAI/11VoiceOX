11VoiceOX.in 0.5.7 : téléphones, CPU et application plus sereine

Applications iOS et Android en aperçu, version CPU pour les PC sans GPU et interface plus calme. Les changements à connaître avant la mise à jour.

Par Palash Debnath · 2026-10-26 · 4 min de lecture

L'application convient à plus de machines et demande moins d'efforts

11VoiceOX.in 0.5.7 est une version importante, arrivée plus tard que prévu. Les notes s'ouvrent sur des excuses pour l'attente et des remerciements pour la patience et les signalements reçus. Elles accueillent aussi Shimul Debnath (velixio) dans l'équipe principale pour examiner les pull requests, trier les tickets et faire avancer les versions.

Trois changements comptent particulièrement pour les utilisateurs :

  • Téléphones. Les applications iOS et Android en aperçu exécutent les modèles sur le téléphone.
  • Sans GPU. Les PC sans GPU dédié reçoivent une petite version CPU de PyTorch et peuvent exécuter l'application.
  • Moins d'encombrement. La barre latérale et les pages Models, Dubbing, Stories et Workflows ont été reconstruites autour de commandes moins nombreuses et plus claires.

Il existe aussi un canal de mise à jour Beta facultatif, un lecteur inférieur pour les prises et un panneau d'accélération GPU qui identifie correctement les cartes Radeon. Les notes recensent des centaines de corrections pour le clonage, le doublage, les livres audio, les téléchargements et la dictée ; cet article ne les énumère pas.

11VoiceOX.in sur téléphone

Les applications mobiles exécutent la parole, la dictée, le clonage vocal et le doublage sur l'appareil. Une fois les modèles téléchargés, elles fonctionnent hors ligne. L'association à un ordinateur est facultative.

Ce sont des aperçus. Android propose un APK à installer directement et un App Bundle pour Google Play. Sur iPhone, vous obtenez un IPA non signé à signer avec votre propre identifiant Apple, par exemple via Sideloadly. Ce n'est pas une version TestFlight ou App Store ; les notes indiquent que la signature App Store est bloquée par la limite de certificats d'Apple.

Si vous avez essayé un aperçu mobile antérieur

Les applications mobiles utilisent désormais l'identifiant sh.11voiceox.mobile. Un aperçu installé auparavant reste à côté de la nouvelle application au lieu d'être mis à jour. Associez à nouveau la nouvelle application et supprimez l'ancienne.

Bienvenue même sans GPU

Une machine sans GPU NVIDIA installe désormais la petite version CPU de PyTorch. Elle demande environ 5 GB libres au lieu de 9 GB et charge les modèles vocaux en float32 au lieu de float16. Les petits modèles s'installent avec seulement 2 GB libres ; la vérification avertit sous 10 GB au lieu de bloquer.

Windows sur ARM reçoit un installateur natif marqué expérimental. Le serveur IA fonctionne en x64 sous émulation, sur le CPU.

Si vous avez un GPU, Settings → Performance → GPU acceleration liste vos cartes, la version PyTorch installée et les moteurs utilisant le GPU ou le CPU, avec la raison. L'installation identifie désormais une Radeon comme telle au lieu d'accuser un pilote NVIDIA manquant.

Une application plus calme

L'essentiel du travail visible simplifie l'interface. La barre latérale devient une mince colonne d'icônes à côté du panneau de chaque section. Settings → Models affiche une liste par famille : installation, acceptation de licence et sélection se font sur la même ligne. Les prises récentes et l'audio du projet passent dans un lecteur inférieur doté d'une forme d'onde navigable.

Dubbing présente la source sur une ligne, un aperçu du fichier chargé et signale les fichiers sans son par une note plutôt qu'une erreur. Workflows ouvre les modèles par un sélecteur, ajoute des étapes depuis une barre d'outils sur le canevas et signale les réglages manquants avant l'exécution. Les échecs de génération ou de démarrage d'un moteur indiquent une cause probable et une solution.

Autres petites nouveautés :

  • Rechercher et remplacer dans la transcription Dubbing, avec annulation en une étape
  • Curseur de volume de fond pour les exports de doublage, de 0 à 400%
  • Limites de vitesse Smart Fit dans la section Timing
  • Portugais du Brésil et du Portugal comme langues distinctes
  • Ouïghour comme langue cible, avec lecture de droite à gauche des écritures concernées

La liste complète et les crédits figurent dans les notes de version v0.5.7.

Avant la mise à jour

Certaines modifications peuvent interrompre un usage qui fonctionnait auparavant.

  • Licences de modèles. Les modèles sans licence clairement commerciale, dont OmniVoice par défaut, demandent une acceptation unique dans Model Catalogue. Avant cette acceptation, les requêtes API et MCP qui les utilisent renvoient une erreur de licence.
  • Le calcul distant passe à Pro. Les appareils et workers de calcul distant et le partage GPU ne sont plus dans l'application open source. Les projets, voix et réglages enregistrés ne sont pas affectés.
  • Noms d'hôte. Accéder à Docker, un réseau local ou un proxy inverse par nom d'hôte sans clé API ni session exige que ce nom figure dans OMNIVOICE_ALLOWED_HOSTS. Les adresses IP, localhost, *.ts.net et host.docker.internal fonctionnent comme avant.
  • Imports d'URL privées. Importer depuis un serveur de votre réseau nécessite OMNIVOICE_ALLOW_PRIVATE_URL_IMPORTS=1.
  • Depuis Tauri. Tauri v0.5.3 est la dernière version Tauri et son outil de mise à jour ne peut pas installer Electron. Fermez l'application, sauvegardez son répertoire de données, installez Electron et vérifiez vos voix et projets avant de supprimer Tauri. Le guide de migration détaille les étapes.

Les deux variables d'environnement vont dans ~/.config/omnivoice/env sur macOS et Linux, ou %USERPROFILE%\.config\omnivoice\env sur Windows. Pour Docker, transmettez-les avec -e. Le guide d'authentification API donne les détails.

Comment mettre à jour

Installez par-dessus votre application Electron existante. Voix, projets et réglages sont conservés. Si l'installation le demande, choisissez Install local runtime pour actualiser les dépendances. Les installateurs sont sur la page de téléchargement et les fichiers Android et iPhone dans les ressources de la version. Vérifiez les téléchargements avec SHA256SUMS.txt.

Pour la confiance : les installateurs macOS sont signés et notariés, et la version Android est signée avec la clé de publication 11VoiceOX.in. Les installateurs Windows ne sont pas encore signés, donc SmartScreen peut avertir. Choisissez More info puis Run anyway. Les paquets Linux ne sont pas signés.

Pour recevoir les correctifs plus tôt, Settings → Updates propose Stable ou Beta. Les Beta sont des préversions -beta.N jamais distribuées aux utilisateurs Stable ; vous passez automatiquement à la prochaine version stable. Docker reçoit les tags :beta correspondants.

Commencez par ouvrir le panneau d'accélération GPU et lire ses informations sur votre machine. Pour créer ensuite une voix, consultez le guide de clonage local.
