مفت ڈیسک ٹاپ ایپ

شامل مقامی کلوننگ، ڈبنگ، ٹرانسکرپشن اور آواز کے کام آپ کی مشین پر چلتے ہیں۔ ان کی ریکارڈنگ، تیار کردہ آڈیو، ٹرانسکرپٹس اور اخذ کردہ صوتی ڈیٹا آپ کے زیرِ اختیار ذخیرے میں لکھا جاتا ہے؛ یہ ویب سائٹ اور 11VoiceOX.in کنٹرول پلین انہیں وصول نہیں کرتے۔

جب آپ اپ ڈیٹس چیک کرنے، ماڈل ڈاؤن لوڈ کرنے یا واضح طور پر نیٹ ورک پر مبنی اڈاپٹر ترتیب دینے کو کہیں تو ایپ نیٹ ورک استعمال کر سکتی ہے۔ ایسا اڈاپٹر پراسیسنگ کا الگ انتخاب ہے اور اس فراہم کنندہ کے نوٹس اور شرائط پر چلتا ہے۔ مقامی استعمال اکاؤنٹ، API کلید یا Cloud کنکشن کے بغیر دستیاب رہتا ہے۔

11VoiceOX Pro

Pro آواز، ڈبنگ اور ٹرانسکرپشن کا کام آپ کے کمپیوٹر پر چلاتا ہے اور وہ فائلیں ہمیں نہیں بھیجی جاتیں۔ Pro چلانے کے لیے ایپ آپ کو سائن ان کرتی ہے اور آپ کا لائسنس جانچتی ہے، اس لیے نیچے دیا گیا ڈیٹا بھیجا جاتا ہے۔ جو سہولتیں آپ خود آن کرتے ہیں، جیسے ریموٹ ورکرز، سیٹنگز سنک یا آن لائن مترجم، وہ اپنی ضرورت کا ڈیٹا آپ کی چنی ہوئی منزل پر بھیجتی ہیں۔

اکاؤنٹ۔ آپ id.11voiceox.in پر ہماری اپنی شناختی سروس کے ذریعے سائن ان کرتے ہیں۔ اس میں آپ کا ای میل پتہ، نام اور پروفائل کی تفصیلات ہوتی ہیں اور یہ ہر سائن ان کو اس کے وقت، IP پتے، ملک اور براؤزر کی تفصیلات کے ساتھ درج کرتی ہے۔ سائن ان کے واقعات اور سیشن کی نیٹ ورک تفصیلات 90 دن بعد ہٹا دی جاتی ہیں۔

لائسنس اور آلات۔ آلہ فعال کرنے پر ایک بے ترتیب انسٹالیشن ID، آلے کا نام (جب تک آپ نہ بدلیں، آپ کے کمپیوٹر کا ہوسٹ نیم)، پلیٹ فارم، ایپ ورژن، آپریٹنگ سسٹم ورژن اور آلے کی کلید بھیجی جاتی ہے۔ ہر لائسنس جانچ IP پتہ، اس کا ملک اور وقت بھی درج کرتی ہے، جو اس آلے کے ریکارڈ کی سابقہ قدروں کی جگہ لے لیتے ہیں۔ آپ کے آلات آپ کے اکاؤنٹ میں نظر آتے ہیں اور کسی تنظیم کے منتظمین اس کے اراکین کے آلات دیکھ سکتے ہیں۔ درست لائسنس Pro کو 72 گھنٹے تک آف لائن چلتا رکھتا ہے۔

آزمائش۔ فی اکاؤنٹ اور آلہ ایک آزمائش کی اجازت دینے کے لیے ہم اکاؤنٹ، آغاز اور اختتام کی تاریخیں، اور بے ترتیب انسٹالیشن ID اور آلے کی کلید کے ہیش رکھتے ہیں۔ ہم ہارڈویئر شناخت کنندہ استعمال نہیں کرتے۔ یہ ریکارڈ اکاؤنٹ حذف ہونے کے بعد بھی رکھا جاتا ہے۔

سیٹنگز سنک۔ یہ بطور ڈیفالٹ بند ہے۔ اسے آن کرنے پر آپ کی سیٹنگز، شارٹ کٹس، پسندیدہ اشیا اور آلے کی ترجیحات آلے کے نام، پلیٹ فارم، ایپ ورژن، IP پتے اور ملک کے ساتھ ہمارے سرورز پر محفوظ ہوتی ہیں۔ یہ ڈیٹا اینڈ ٹو اینڈ انکرپٹڈ نہیں ہے، اس لیے ہم اسے پڑھ سکتے ہیں۔ وائس سنک بطور ڈیفالٹ بند ہے۔ سنک بند کرنے سے سنک رک جاتا ہے؛ کلاؤڈ سے ڈیٹا ہٹانے کا انتخاب کرنے پر وہ حذف ہو جاتا ہے۔

آپ کا اپنا سنک اسٹوریج۔ آپ کے اپنے WebDAV یا S3 سرور پر سنک اپ لوڈ سے پہلے اینڈ ٹو اینڈ انکرپٹ ہوتا ہے اور ہم تک کچھ نہیں پہنچتا۔

استعمال کا تجزیہ۔ Pro ڈیسک ٹاپ ایپ استعمال اور خرابی کا میٹا ڈیٹا خودکار طور پر Supermetry (app.supermetry.com) کو بھیجتی ہے اور اسے بند کرنے کا کوئی سوئچ نہیں۔ اس میں دیکھی گئی اسکرینیں، استعمال شدہ سہولتیں، سیشن، انسٹالیشنز، اپ ڈیٹس، کریشز اور خرابیوں کی عمومی اقسام شامل ہیں، جو ایک بے ترتیب انسٹالیشن ID اور آپ کے سائن ان ہونے پر ہیش شدہ اکاؤنٹ ID سے منسلک ہوتی ہیں۔ اس میں آپ کا متن، آڈیو، فائلیں، اصل خرابی کے پیغامات، ای میل پتہ یا اکاؤنٹ ID کبھی شامل نہیں ہوتے۔ Pro فون ایپس پہلے پوچھتی ہیں اور ان میں رازداری کا سوئچ ہے۔

ڈیش بورڈ کی سرگرمی۔ جب آپ ڈیش بورڈ میں سائن ان ہوتے ہیں تو ہم ریکارڈ کرتے ہیں کہ کس قسم کا صفحہ کھلا ہے، ٹیب استعمال میں ہے یا نہیں، آپ کے اہم اقدامات اور پیش آنے والی خرابیاں، تاکہ ہماری سپورٹ ٹیم دیکھ سکے کہ آپ کو کب مدد درکار ہو سکتی ہے۔ اسے صرف ہماری ٹیم دیکھ سکتی ہے، ہر بار دیکھنے کا ریکارڈ رکھا جاتا ہے، اور ہم اسے 30 دن رکھتے ہیں اور آپ کے اکاؤنٹ کے ساتھ حذف کر دیتے ہیں۔ آپ جو ٹائپ کرتے ہیں اسے ہم کبھی ریکارڈ نہیں کرتے، اور اگر آپ کا براؤزر Do Not Track یا Global Privacy Control بھیجے تو ہم کچھ بھی ریکارڈ نہیں کرتے۔

اپ ڈیٹس۔ اپ ڈیٹ جانچ appapi.11voiceox.in پر جاتی ہے۔ مستحکم جانچ میں کوئی اسناد نہیں ہوتیں اور بیٹا جانچ میں آپ کے اکاؤنٹ کا ٹوکن ہوتا ہے۔ انسٹالرز قلیل مدتی لنکس کے ذریعے Cloudflare R2 سے ڈاؤن لوڈ ہوتے ہیں۔

بگ اور مواد کی رپورٹس۔ بگ رپورٹس صرف تب بھیجی جاتی ہیں جب آپ انہیں بھیجنا چنیں یا خودکار کریش رپورٹس آن کریں، جو بطور ڈیفالٹ بند ہیں۔ لاگز سے پہلے ٹوکن اور ہوم فولڈر کے راستے ہٹا دیے جاتے ہیں۔ اگر آپ فون پر مواد کی رپورٹ میں بھیجیں پر ٹیپ کریں تو ہمیں وجہ، آپ کا نوٹ، آپ کا شامل کردہ کوئی بھی پرامپٹ متن، اور پلیٹ فارم، ایپ ورژن اور ماڈل موصول ہوتے ہیں۔ ہم اسے 180 دن رکھتے ہیں۔

آپ کا اکاؤنٹ حذف کرنا۔ ڈیش بورڈ میں حذف کرنے کی درخواست دیں، جسے آپ ایپ میں سیٹنگز ← اکاؤنٹ سے کھول سکتے ہیں۔ جائزے کے بعد، اور منظوری کے سات دن کے اندر، ہم آپ کا محفوظ مواد، سنک شدہ ڈیٹا اور اسناد حذف کرتے ہیں، آپ کا لاگ ان حذف کرتے ہیں اور آپ کے صارف ریکارڈ کو گمنام بناتے ہیں۔ ٹیکس، فراڈ کی روک تھام اور لائسنس ریکارڈ کے لیے ہم آرڈرز، ادائیگیاں، لائسنس، آلات کے ریکارڈ (آلے کے نام اور آخری IP پتے سمیت)، استعمال، آڈٹ اور آزمائش کے ریکارڈ رکھتے ہیں۔

ویب سائٹ کی ترسیل اور بیرونی وسائل

Cloudflare اس سائٹ اور اسی origin کے API راستے فراہم کرتا ہے۔ اسے لازماً درخواست کا میٹا ڈیٹا، جیسے IP پتہ، یوزر ایجنٹ، مطلوبہ URL، وقت اور سیکیورٹی سگنلز پراسیس کرنا ہوتا ہے۔ سائٹ اشتہاری کوکیز نہیں لگاتی، اشتہاری اسکرپٹس نہیں چلاتی اور آنے والوں کی معلومات نہیں بیچتی۔

آپ کا براؤزر GitHub سے منتظم کا اوتار اور Trendshift سے درجہ بندی کا بیج براہ راست طلب کر سکتا ہے۔ ان خدمات کو درخواست کا عام میٹا ڈیٹا ملتا ہے، بشمول آپ کا IP پتہ اور اس سائٹ کا صرف origin کی سطح کا ریفرر۔ اسٹار، ریلیز اور ڈاؤن لوڈ کا میٹا ڈیٹا ہمارا سرور حاصل کرتا ہے۔ فونٹس، پہلے سے ریکارڈ آڈیو اور دیگر سائٹ اثاثے اسی ڈومین سے فراہم ہوتے ہیں۔

ویب سائٹ تجزیات

ہم اپنے چلائے ہوئے تجزیاتی سافٹ ویئر سے عوامی صفحات کا استعمال ناپتے ہیں، جن میں app.supermetry.com اور plausible.11voiceox.in شامل ہیں؛ کسی تیسرے فریق کی تجزیاتی سروس کو ڈیٹا نہیں ملتا۔ صفحہ دیکھنے پر یہ صفحے کا پتہ، ریفرر، اسکرین کی چوڑائی، صفحہ کھلا رہنے کا وقت اور اسکرول کی گہرائی بھیجتا ہے۔ یہ کوکی نہیں لگاتا اور براؤزر میں کچھ محفوظ نہیں کرتا۔ ہر ویب سرور کی طرح ہمارا سرور بھی یہ واقعات لے جانے والی درخواست کا IP پتہ اور براؤزر یوزر ایجنٹ دیکھتا ہے۔

یہ صرف عوامی صفحات (ہوم، مصنوعات، دستاویزات اور چیک آؤٹ) پر چلتا ہے، سائن ان شدہ ایپ میں کبھی نہیں، اور جب براؤزر Do Not Track یا Global Privacy Control بھیجے تب بھی نہیں۔

متن سے آواز کا پیش نظارہ

Studio کی نمائش اور صوتی کارڈز زیادہ تر پہلے سے ریکارڈ آڈیو چلاتے ہیں اور کبھی مائیکروفون تک رسائی نہیں مانگتے۔ قابلِ ترمیم متن سے آواز کا پیش نظارہ استعمال کرنے پر اسی origin کا راستہ زیادہ سے زیادہ 200 حروف اور منتخب آواز کی ترتیبات وصول کرتا ہے۔ اگر جائزہ شدہ 11VoiceOX.in پیش نظارہ بیک اینڈ ترتیب دیا گیا ہو تو راستہ درخواست حسبِ طلب آواز بنانے کے لیے اسے بھیجتا ہے؛ ورنہ شامل نمونہ واپس کرتا ہے۔ پیش نظارے کا متن کبھی تیسرے فریق کے TTS فراہم کنندہ کو نہیں بھیجا جاتا۔

ایپ پیش نظارے کا متن یا تیار کردہ آڈیو مستقل محفوظ نہیں کرتی اور درخواست کی باڈی ایپ لاگز میں شامل نہیں کرتی۔ ہوسٹنگ ایج اب بھی اوپر بیان کردہ عام HTTP میٹا ڈیٹا پراسیس کرتا ہے۔ عوامی پیش نظارے میں راز، ذاتی ڈیٹا یا ایسا متن نہ ڈالیں جسے پراسیس کرنے کی آپ کو اجازت نہیں۔

ابتدائی رسائی اور تجارتی استفسارات
