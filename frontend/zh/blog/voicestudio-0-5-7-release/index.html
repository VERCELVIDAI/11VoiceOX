11VoiceOX.in 0.5.7：手机、CPU 与更清爽的应用

iOS 和 Android 应用预览、面向无 GPU 电脑的 CPU 构建，以及更清爽的应用。更新前还有值得了解的变化。

应用适配更多设备，使用更省心

11VoiceOX.in 0.5.7 是一次大规模更新，发布时间比应有的更晚。发行说明首先为等待致歉，并感谢大家的耐心和期间提交的反馈。同时欢迎 Shimul Debnath（velixio）加入核心团队，协助审核拉取请求、分类问题并推进发行。

对于应用用户，三个变化最重要：

  • 手机。iOS 和 Android 预览应用直接在手机上运行模型。
  • 无 GPU。没有独立 GPU 的电脑可以安装小型 CPU 版 PyTorch 并运行应用。
  • 更少杂乱。侧边栏以及 Models、Dubbing、Stories 和 Workflows 页面经过重建，控件更少更清晰。

此外还有可选的 Beta 更新频道、用于播放生成片段的底部播放器，以及能够正确显示 Radeon 显卡的 GPU 加速面板。发行说明列出克隆、配音、有声书、下载和听写方面数百项修复；本文不逐一列出。

手机上的 11VoiceOX.in

手机应用在设备上运行语音、听写、声音克隆和配音。下载模型后可离线使用，连接电脑是可选的。

这些是预览版。Android 提供可直接安装的 APK 以及适用于 Google Play 的 App Bundle。iPhone 提供未签名的 IPA，您需要使用自己的 Apple ID 签名，例如通过 Sideloadly。它不是 TestFlight 或 App Store 版本；发行说明称 Apple 的证书数量限制阻碍了 App Store 签名。

如果您试用过早期手机版预览

手机应用现在使用应用 ID sh.11voiceox.mobile。此前安装的预览版不会被更新，而是与新应用并存。请重新配对新应用并删除旧版。

没有 GPU 也欢迎

没有 NVIDIA GPU 的设备现在安装小型 CPU 版 PyTorch。它需要约 5 GB 可用空间，而非 9 GB，并以 float32 而非 float16 加载声音模型。小模型最低可在 2 GB 空闲磁盘空间下安装；安装检查在低于 10 GB 时只发出警告，不会阻止。

Windows on ARM 获得标记为实验性的原生安装程序。AI 后端通过仿真以 x64 模式在 CPU 上运行。

如果您有 GPU，Settings → Performance → GPU acceleration 会列出显卡、已安装的 PyTorch 版本，以及各引擎使用 GPU 或 CPU 的情况和原因。安装程序现在会正确标识 Radeon 显卡，而不是归咎于缺少 NVIDIA 驱动。

更简洁的应用

大部分可见变化是简化。侧边栏变成各区域面板旁的窄图标栏。Settings → Models 按模型家族分组，您可以在同一行安装引擎、接受许可并选择引擎。最近生成的片段和项目音频在底部播放器中播放，并可通过波形定位。

Dubbing 将来源放在一行，提供已加载文件的预览，并以提示而非错误报告无声文件。Workflows 通过选择器打开模板，从画布工具栏添加步骤，并在运行前标记缺失的设置。生成或引擎启动失败时，现在会显示可能原因和解决办法。

其他实用小改进：

  • 在 Dubbing 转录中查找和替换，可一步撤销编辑
  • 配音导出的背景音量滑块，范围为 0 到 400%
  • 在 Timing 区域设置 Smart Fit 速度限制
  • 巴西葡萄牙语和葡萄牙葡萄牙语作为独立选项
  • 维吾尔语作为配音目标语言，并正确显示从右到左的文字

完整列表和贡献者致谢见v0.5.7 发行说明。

更新之前

部分更改可能导致之前正常使用的功能暂时无法工作。

  • 模型许可证。包括默认 OmniVoice 在内，没有明确商业许可的模型要求您在 Model Catalogue 中接受一次许可证。在此之前，使用它们的 API 和 MCP 请求会返回许可证错误。
  • 远程计算移至 Pro。远程计算设备、远程工作节点和 GPU 共享不再包含在开源应用中。已保存的项目、声音和设置不受影响。
  • 主机名。没有 API 密钥或会话时，通过主机名访问 Docker、局域网或反向代理需要将名称列入 OMNIVOICE_ALLOWED_HOSTS。IP 地址、localhost、*.ts.net 和 host.docker.internal 与之前一样可用。
  • 私有 URL 导入。从自己网络中的服务器导入需要 OMNIVOICE_ALLOW_PRIVATE_URL_IMPORTS=1。
  • 从 Tauri 迁移。Tauri v0.5.3 是最后一个 Tauri 版本，其更新程序无法安装 Electron。请关闭应用、备份数据目录、安装 Electron，并在删除 Tauri 前检查声音和项目。步骤见迁移指南。

两个环境变量在 macOS 和 Linux 上放入 ~/.config/omnivoice/env，在 Windows 上放入 %USERPROFILE%\.config\omnivoice\env。Docker 使用 -e 传入。详情见API 身份验证指南。

如何更新

在现有 Electron 应用上直接安装，声音、项目和设置会保留。如安装程序提示，选择 Install local runtime 更新依赖。安装程序位于下载页面，Android 和 iPhone 文件位于发行资源中。使用 SHA256SUMS.txt 校验下载。

关于可信性：macOS 安装程序已签名并经过公证，Android 版本使用 11VoiceOX.in 发行密钥签名。Windows 安装程序尚未进行代码签名，因此 SmartScreen 可能发出警告。选择 More info，然后选择 Run anyway。Linux 软件包未进行代码签名。

若希望更早获得修复，可在 Settings → Updates 中选择 Stable 或 Beta。Beta 是 -beta.N 预发布版本，不会推送给 Stable 用户；您会自动进入下一稳定版本。Docker 提供对应的 :beta 标签。

首先打开 GPU 加速面板，阅读有关您设备的信息。接下来若想创建声音，请从本地克隆指南开始。
